Tooling for the AI-agent era, shipped in public: agent security, MCP integrations and developer experience for Upstox's trading APIs.

harness-gauntlet

Creator

Lint and red-team the loop your AI coding agents run.

A static auditor plus a live red-team for AI coding-agent harnesses. It scans Claude Code agent configs for missing guardrails, then rebuilds each agent in a throwaway sandbox and fires 20 attacks across 9 families (prompt injection, secret exfiltration, destructive actions, scope escalation, SSRF, supply chain) mapped to the OWASP LLM and Agentic Top 10. A PreToolUse deny-and-log tripwire measures what the agent actually attempted, producing defense and resilience scores that can gate CI.

What is harness-gauntlet?

harness-gauntlet is Ninad Malvankar's open-source tool for testing the guardrails of AI coding agents. A static scan reads Claude Code agent and harness config for missing protections; a dynamic red-team rebuilds each agent in a sandbox and runs 20 attacks across 9 families (prompt injection, secret exfiltration, destructive actions, scope escalation and more), mapped to the OWASP LLM Top 10 2025 and Agentic Top 10 2026. It reports defense and resilience scores and can fail a CI build. Source: github.com/elninad/harness-gauntlet.

His focus is applied AI engineering (agents, tooling, guardrails, developer workflows) on top of a long platform and cloud background.
